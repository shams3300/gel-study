# Gel Study

The gel study from Spike Cove: Halcyon Labs, a live multiplayer world on Spawn.

- `places/gel/`: the gel room's setup, scene and screen layout.
- `scripts/gel/`: the body, mannequins, figures, gel material, studio and camera.
- `scripts/gel-player.js`: the player in the gel room.
- `art/athletic-gel/`, `art/athletic-gel-v2/`, `art/athletic-tripo/`: the athletic gel figure builds.

Design note (2026-11-14): athletic gel figure rebuilt on Blender's human builder (MPFB) base, dialed to the painted sheet.
